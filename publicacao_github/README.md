# Atlas Bíblico — Site online com bases incorporadas

Esta pasta é o site completo para publicação. **Não envie apenas um arquivo ZIP.**

Bancos publicados em `dados/`:
- `enciclopedia_total.js`: personagens, lugares e acontecimentos;
- `biblia_completa.json`: texto português de 66 livros;
- `cross_references*.txt`: referências cruzadas.

O site busca somente os arquivos do próprio domínio GitHub Pages; não exige API externa nem servidor de banco de dados.
O visitante precisa de internet para acessar o site; os dados são servidos pelo GitHub Pages.

Créditos e limites: [FONTES_E_LIMITES.md](FONTES_E_LIMITES.md).
